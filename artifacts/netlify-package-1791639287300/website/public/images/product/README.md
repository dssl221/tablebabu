# Product screenshots

These are actual TableBabu interface captures using illustrative test restaurant data, converted to WebP without changing the interface content. They contain no production customer or employee records.

All three images are fresh captures from the TableBabu application. Run `npx tsx scripts/capture-product.ts` against the local development server to refresh them. The script creates an isolated sample restaurant and guest session, captures the owner overview, menu management, and customer menu, then removes its database fixtures and scoped throttle entries.

Sample food photography is documented in `../CREDITS.md`. Refresh these captures when the corresponding product screens change. Image alternative text identifies these as actual interface captures with sample data. The homepage product tabs switch between screenshots; they do not operate a live restaurant workspace.
