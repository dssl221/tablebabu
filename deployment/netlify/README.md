# TableBabu temporary deployment package

This package has two deployments. Netlify hosts the public homepage with the existing animations and product screenshots. The separate Node application hosts login, signup, dashboards, QR menus, ordering, billing, legal pages and privacy requests. Navigation to those pages changes to the application domain; this is intentional. Netlify does not proxy APIs or WebSockets. No application functionality was replaced with mock responses.

## 1. Deploy backend first

Use `backend/` on a Node 24 host with long-running processes, HTTPS, WebSocket support and persistent storage. PostgreSQL must be reachable privately or over TLS. This package contains schema/migrations, NOT your existing database, accounts, orders or uploaded images. For an existing deployment, transfer its data using a separately secured backup and restore process.

Set DATABASE_URL, APP_ORIGIN (the exact HTTPS application origin, e.g. https://app.tablebabu.in), PORT and TRUST_PROXY. APP_ORIGIN must be the application origin, not Netlify. Set TRUST_PROXY=1 only behind exactly one trusted proxy that cannot be bypassed. Preserve `/app/uploads` in Docker or `uploads/` for a normal Node deployment.

For a normal Node host:

```
npm ci
npm run db:migrate
npm run build
npm start
```

For Docker, use the included Dockerfile. Run migrations as a separate release step with development dependencies installed (`npm ci` then `npm run db:migrate`); the runtime image does not include the Prisma migration CLI. Supply build-time APP_ORIGIN/DATABASE_URL if your build environment requires them; never bake credentials into the image. No database migration or admin provisioning runs automatically on startup.

Check HTTPS `/api/health`, signup/login, uploads, Socket.IO connections and the customer ordering/billing journey. Provision a NEW admin if needed using `npm run admin:create` with PLATFORM_ADMIN_NAME, PLATFORM_ADMIN_EMAIL and PLATFORM_ADMIN_PASSWORD supplied securely, then remove the password environment variable. Existing local accounts are not bundled.

Keep SECURE cookies, CSRF origin checks and the existing CSP enabled. Do not add wildcard CORS. QR codes generated by the backend point to its APP_ORIGIN; keep that domain stable. Review SECURITY.md and INDIA-COMPLIANCE.md before accepting real data.

## 2. Deploy website on Netlify

Import **website/** as a standalone repository, or use the package repository with Netlify base directory **website**. Build command: `npm run build`. Publish directory: `out`. Node: 24. The supplied netlify.toml sets these options. Disable any manually installed Next.js runtime plugin for this static export.

Add `TABLEBABU_APP_ORIGIN=https://YOUR-ACTUAL-APP-HOST` to Netlify's build environment. Netlify supplies `URL` for the website origin. No database URL, admin password or session secrets belong in the Netlify website project. The build intentionally fails if the backend origin is missing or matches the website origin. Redeploy after changing domains.

Alternatively, build website locally with TABLEBABU_APP_ORIGIN and TABLEBABU_SITE_ORIGIN set to the two actual HTTPS origins, run `npm ci` and `npm run build`, then drag the **out/** folder into Netlify Drop. Do not upload this source ZIP as a ready-built static website.

After deployment verify homepage images, product tabs, mobile navigation and all signup/login/legal links. Confirm these links navigate to your application host. Test a real guest QR flow and simultaneous dashboard updates on that host. Netlify branch previews also point to the configured backend; use a staging backend for previews that should not affect production.

## Scope and packaging

Created from explicit source allowlists. Excludes `.env`, local PostgreSQL, uploads, node_modules, build outputs, test artifacts and logs. This is deployment source, not a database backup. Neither deployment has been published or connected to live infrastructure by this packaging operation.

Rebuild this package from the main project with `node scripts/package-netlify.mjs`. Generated packages are under artifacts/. The application itself is unchanged.

Netlify reference: https://docs.netlify.com/build/frameworks/framework-setup-guides/nextjs/overview/
